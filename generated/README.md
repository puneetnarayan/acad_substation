# Generated Substation Layout Artifacts

Stable artifacts for the cable-scheduling integration:

- `substation_layout.dxf` — ASCII DXF drawing; open with AutoCAD and save as DWG.
- `substation_layout.json` — structured settings, panel IDs/locations, openings and bus ducts.

Raw URLs:
- DXF: https://raw.githubusercontent.com/puneetnarayan/acad_substation/main/generated/substation_layout.dxf
- JSON: https://raw.githubusercontent.com/puneetnarayan/acad_substation/main/generated/substation_layout.json

The committed files use illustrative sample data. In the layout app, use **Publish latest to GitHub** to update both artifacts. The app asks for a narrowly scoped GitHub token at publish time; it keeps that token in the current tab's session only. Verify geometry in AutoCAD before engineering use.
