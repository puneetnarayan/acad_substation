Panel schedule

One row per cubicle. Width is along the lineup, depth is across it. Sample data is illustrative only; replace it with approved vendor dimensions and clearances.

Room geometry

Room coordinates use bottom-left as (0,0). This prototype draws a rectangular room and a straight lineup; multi-lineup and irregular wall geometry are planned enhancements.

Doors and windows

Position is measured from the start of the selected wall. For the initial preview, openings are shown as markers on the referenced wall; confirm swing and elevation details in AutoCAD.

HT / LV bus duct entries

Coordinates are opening centre points in room coordinates. Use the vendor-approved dimensions and elevations. Electrical clearances are not automatically certified.

Live plan preview

Schematic preview only. It is not a scaled construction drawing. Dimensions, annotation, openings and clearances must be checked in AutoCAD.

Workflow

  1. Edit the panel schedule and room dimensions.
  2. Review the plan preview and input checks.
  3. Export panels CSV or project JSON as a backup.
  4. Download the AutoLISP file and CSV bundle. Transfer the CSV and LISP to a Windows computer with full AutoCAD.
  5. In AutoCAD, load the LISP using APPLOAD, then run command ACAD_SUBSTATION and select the exported panel CSV.
  6. Review generated geometry, dimension styles, text size, door swings, openings and all electrical clearances before issuing a drawing.
Important: This is an early prototype. Browser hosting cannot directly control your local AutoCAD or access local files without an explicit file-selection/download step. The exported LISP is intended as a starting point for local drawing generation; validate it on a test drawing first. Do not use the output for construction without engineering review.

Data handling

Project edits are saved in this browser's local storage. Export a JSON backup before clearing browser data. The hosted GUI does not upload your project data to a server.
