Workflow

  1. Edit the panel schedule and room dimensions.
  2. Review the plan preview and input checks.
  3. Export panels CSV or project JSON as a backup.
  4. Download the AutoLISP file and CSV bundle. Transfer the CSV and LISP to a Windows computer with full AutoCAD.
  5. In AutoCAD, load the LISP using APPLOAD, then run command ACAD_SUBSTATION and select the exported panel CSV.
  6. Review generated geometry, dimension styles, text size, door swings, openings and all electrical clearances before issuing a drawing.
Important workflow & data handling

The browser cannot control local AutoCAD directly. Export project data and load the LISP with APPLOAD. The current LISP draws panel footprints and labels only; verify on a test drawing. Data stays in this browser local storage; export a JSON backup.
